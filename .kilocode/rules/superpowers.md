# Superpowers Workflow

Before writing any code, follow this process using the skill files in .kilocode/skills/:

1. Brainstorming - refine the idea via questions before touching code (.kilocode/skills/brainstorming/SKILL.md)
2. Writing plans - break work into small tasks with exact file paths (.kilocode/skills/writing-plans/SKILL.md)
3. Using git worktrees - isolated branch workspace, clean baseline (.kilocode/skills/using-git-worktrees/SKILL.md)
4. Test-driven development - RED-GREEN-REFACTOR, write failing test first (.kilocode/skills/test-driven-development/SKILL.md)
5. Executing plans / subagent-driven-development - work through tasks with review checkpoints (.kilocode/skills/executing-plans/SKILL.md, .kilocode/skills/subagent-driven-development/SKILL.md)
6. Systematic debugging - root-cause process, not guessing (.kilocode/skills/systematic-debugging/SKILL.md)
7. Requesting code review - review against plan before marking done (.kilocode/skills/requesting-code-review/SKILL.md)
8. Verification before completion - confirm it actually works before declaring done (.kilocode/skills/verification-before-completion/SKILL.md)
9. Finishing a development branch - merge/PR/cleanup decision (.kilocode/skills/finishing-a-development-branch/SKILL.md)

Check the relevant skill file before starting any task. These are mandatory steps, not suggestions. Do not skip ahead to writing code without brainstorming and a plan first.
